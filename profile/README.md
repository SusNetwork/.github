『🚪』SusNetwork is a private server for Among Us, including:

- 『🛃』Custom FriendCodes (ex: johndoe#0001)
- 『🤖』Android support (through BepInEx.Fusion)
- 『➕』Custom features and enhancements

『🛠️』It works using a BepInEx plugin and a recreation of the Among Us authentication protocol in C# (.NET)

『❌』Our authentication reimplantation is closed source, only a Lite version is available.

『💻』SusNetwork is still in development and is not publicly available yet.
